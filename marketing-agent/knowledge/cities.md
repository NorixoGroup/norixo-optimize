# Cities Knowledge

## Source actuelle

Norixo dispose deja d'un jeu de pages villes orientees marche local, par
exemple :

- Paris
- London
- Barcelona
- Lisbon
- Rome
- Marrakech
- Dubai

## Utilisation editoriale

Les pages villes permettent de produire des contenus :

- ancrés dans un marche
- utiles pour les hotes qui comparent leur annonce
- plus concrets qu'un conseil trop general

## Angles editoriaux possibles

- ce que regardent les voyageurs dans cette ville
- comment les annonces se comparent localement
- quels details rassurent le plus
- quels angles photos ou amenities comptent localement
- comment parler d'un quartier ou d'un acces

## Regles

- ne pas inventer de statistiques
- rester qualitatif si l'info n'est pas numerique
- utiliser la ville comme contexte, pas comme pretexte
- faire un lien entre contexte local et action sur l'annonce
