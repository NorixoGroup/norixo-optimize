# Image Prompt

## Main Prompt

Create a clean editorial social media visual for Norixo Optimize about Booking
description optimization.

Style:

- modern SaaS brand visual
- premium but accessible
- sharp, bright, professional
- no aggressive advertising look

Color direction:

- warm off-white background
- deep slate text blocks
- subtle gold or amber accent
- restrained coral highlights for key friction points

Composition:

- split layout
- left side shows a weak generic listing description in a muted card
- right side shows a clearer, more structured Booking description in a stronger
  highlighted card
- central transition cue suggesting "from vague to bookable"

Elements to show:

- Booking-style listing copy blocks
- readability improvements
- trust signals
- practical guest-facing structure
- subtle Norixo product intelligence feel

Text mood:

- expert
- clear
- conversion-focused
- not salesy

Format:

- primary: portrait 4:5 for Instagram
- secondary crop: square 1:1
- tertiary crop: vertical story 9:16

## Variants

### Variant 1

Before / after card comparison with stronger visual emphasis on clarity.

### Variant 2

Editorial carousel cover with a large title such as:
"Booking description: vague or bookable?"

### Variant 3

Product-style mockup showing an analyzed description with highlighted friction
points and improved wording cues.
