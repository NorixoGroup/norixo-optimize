# Instagram Template

## Usage

Template pour caption courte, mobile-first, facilement lisible.

## Structure recommandee

1. Hook direct
2. 2 ou 3 lignes de valeur
3. mini CTA
4. hashtags limites

## Template

```md
Hook:
[Phrase courte et claire]

Caption:
[2 a 5 lignes courtes]

CTA:
[A enregistrer / a tester / voir le guide]

Hashtags:
[3 a 8 hashtags pertinents]
```

## Exemple de ton

"Votre prix n'est pas toujours le vrai probleme.

Si vos photos rassurent mal ou si votre promesse reste floue, le voyageur sort
avant meme de comparer les details.

A revoir cette semaine : photo hero, titre, amenities."
