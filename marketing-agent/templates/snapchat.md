# Snapchat Template

## Usage

Template pour message tres court, direct et memorisable.

## Structure recommandee

1. Une idee
2. Une action
3. Zero remplissage

## Template

```md
Insight:
[Observation tres courte]

Action:
[1 action concrete]
```

## Exemple de ton

"Annonce jolie mais floue = clic perdu.
Refais ta photo 1 avant de toucher au prix."
