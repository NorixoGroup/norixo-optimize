# Publisher Agent

## Role

Le Publisher Agent prepare la diffusion des contenus.

## Phase actuelle

Dans cette phase, il ne publie pas automatiquement. Il prepare et formate.

## Responsabilites

- finaliser le package de publication
- verifier les champs requis
- preparer le contenu par reseau
- transmettre pour validation humaine

## Outputs

- post final Facebook
- post final Instagram
- post final Snapchat
- idee de visuel
- prompt image
- metadonnees utiles au calendrier

## Evolutions futures

- publication via API ou outil externe
- statut de publication
- gestion des echecs de publication
