# Locale Profiles

## Role

This folder contains the localization profiles used by the future
Localization Agent and reused by the Video Agent, Image Agent, and Publisher.

## Purpose

These profiles do not translate content.

They define the cultural and formatting rules that should guide adaptation for
each supported locale.

## Current Coverage

- fr
- en
- es
- de
- it
- pt
- nl
- ja
- zh
- ko
- ar

## Shared Intent

Each locale profile documents:

- language and primary market
- recommended tone
- formality level
- CTA style
- emoji usage
- recommended length
- cultural rules
- punctuation rules
- hashtag guidance
- video and subtitle notes
- RTL notes when relevant
