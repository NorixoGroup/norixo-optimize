# Performance Model

## Objectif

Le Performance Model decrit les metriques que Norixo AI doit suivre pour
comprendre ce qui fonctionne, comparer les formats et nourrir les decisions
futures.

## Niveau 1 — Visibilite

- impressions
- portee
- vues

## Niveau 2 — Engagement

- likes
- commentaires
- partages
- sauvegardes
- taux d'engagement

## Niveau 3 — Trafic

- clics
- visites site

## Niveau 4 — Conversion

- inscriptions
- audits lances
- conversions
- cout eventuel si campagne payante

## Niveau 5 — Apprentissage

- meilleur sujet
- meilleur format
- meilleur reseau
- meilleur horaire
- meilleur angle a recycler
- contenu a eviter ou retravailler

## Usage

Le modele doit permettre de :

- comparer plusieurs plateformes
- normaliser la lecture des resultats
- distinguer visibilite, engagement, trafic et conversion
- alimenter la boucle d'apprentissage
