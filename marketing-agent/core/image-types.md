# Image Types

## Hero

- objectif : poser le message principal de la campagne
- utilisation : annonce, lancement, page de couverture
- plateformes : Facebook, LinkedIn, X, site, newsletter

## Social

- objectif : accompagner un post social standard
- utilisation : post simple, astuce, update
- plateformes : Facebook, Instagram, LinkedIn, X

## Carousel

- objectif : raconter une sequence visuelle en plusieurs cartes
- utilisation : tutoriel, comparaison, checklist
- plateformes : Instagram, LinkedIn, Facebook

## Before / After

- objectif : rendre un changement visible
- utilisation : optimisation, transformation, valeur prouvee
- plateformes : Instagram, Facebook, LinkedIn

## Quote

- objectif : mettre en avant une phrase forte ou un enseignement
- utilisation : expert insight, rappel, citation
- plateformes : Instagram, LinkedIn, X

## Statistics

- objectif : visualiser une donnee ou une tendance
- utilisation : chiffres, performance, benchmark
- plateformes : LinkedIn, Facebook, Instagram

## Tutorial

- objectif : expliquer un geste ou une methode
- utilisation : how-to, etapes, conseils pratiques
- plateformes : Instagram, Facebook, Pinterest

## Comparison

- objectif : opposer deux options ou deux etats
- utilisation : comparatif, arbitrage, choix
- plateformes : Instagram, LinkedIn, Facebook

## Testimonial

- objectif : renforcer la confiance par la preuve sociale
- utilisation : cas client, retour utilisateur, citation
- plateformes : LinkedIn, Facebook, Instagram

## CTA

- objectif : pousser une action claire sans agressivite
- utilisation : fin de campagne, rappel, conversion
- plateformes : Facebook, Instagram Story, LinkedIn, X

## Regles

- le type d'image doit suivre l'objectif du Campaign Item
- une plateforme peut accepter plusieurs types selon le contexte
- un meme type peut exister en plusieurs formats
