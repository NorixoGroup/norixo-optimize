# Content Source

## Definition

Le Master Content est la source editoriale unique de Norixo AI.

Chaque contenu important doit exister d'abord sous cette forme avant toute
traduction, declinaison sociale, declinaison video ou publication.

## Role

Le Master Content sert de reference commune a tous les agents.

Les autres agents lisent cette source. Ils ne recreent jamais le contenu a
partir de zero lorsqu'une source valide existe deja.

## Attributs de chaque contenu

Chaque Master Content doit posseder au minimum :

- identifiant
- sujet
- categorie
- objectif
- audience
- CTA
- sources
- date
- historique

## Usage par les autres agents

- le Translation Agent adapte le Master Content
- le Social Media Agent le decline par reseau
- le Video Agent le transforme en logique video
- le Publisher Agent l'utilise pour preparer la diffusion
- le Analytics Agent rattache ensuite la performance a cette source

## Regle de gouvernance

- une seule source redigee
- plusieurs declinaisons
- aucune recreation parallele du meme fond
- toute mise a jour importante doit revenir au Master Content
