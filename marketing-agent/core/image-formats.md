# Image Formats

## Instagram Feed

- dimensions : 1080 x 1080
- ratio : 1:1
- usage : post standard, quote, social, comparison

## Instagram Portrait

- dimensions : 1080 x 1350
- ratio : 4:5
- usage : post prioritaire feed, hero, before / after, testimonial

## Story

- dimensions : 1080 x 1920
- ratio : 9:16
- usage : story, CTA, teasing, vertical tutorial

## Facebook

- dimensions : 1200 x 1200 ou 1200 x 630
- ratio : 1:1 ou 1.91:1
- usage : social post, hero, update, comparison

## LinkedIn

- dimensions : 1200 x 1200 ou 1200 x 627
- ratio : 1:1 ou 1.91:1
- usage : product update, case study, statistics, testimonial

## X

- dimensions : 1600 x 900
- ratio : 16:9
- usage : annonce rapide, quote, update, CTA

## Pinterest

- dimensions : 1000 x 1500
- ratio : 2:3
- usage : tutorial, evergreen, checklist, inspiration

## YouTube Thumbnail

- dimensions : 1280 x 720
- ratio : 16:9
- usage : video cover, tutorial video, feature release video

## TikTok Cover

- dimensions : 1080 x 1920
- ratio : 9:16
- usage : vertical video cover, teaser, CTA

## Regles

- le format depend toujours de la plateforme cible
- le meme message peut exister en plusieurs ratios
- les overlays doivent rester lisibles dans le ratio final
