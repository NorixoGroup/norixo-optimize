# Campaign Types

## Feature Launch

- objectif : faire connaitre une nouvelle fonctionnalite
- duree recommandee : 5 a 7 jours
- nombre moyen d'items : 5 a 7
- plateformes privilegiees : Facebook, Instagram, Snapchat
- CTA : decouvrir la fonctionnalite

## Tutorial

- objectif : expliquer comment resoudre un probleme ou utiliser une fonction
- duree recommandee : 3 a 5 jours
- nombre moyen d'items : 3 a 5
- plateformes privilegiees : Facebook, Instagram
- CTA : voir comment faire

## Evergreen SEO

- objectif : transformer un sujet durable en sequence editoriale utile
- duree recommandee : 5 a 10 jours
- nombre moyen d'items : 4 a 6
- plateformes privilegiees : Facebook, Instagram
- CTA : consulter le guide ou approfondir le sujet

## Case Study

- objectif : prouver la valeur via un cas concret
- duree recommandee : 4 a 6 jours
- nombre moyen d'items : 4 a 6
- plateformes privilegiees : Facebook, Instagram
- CTA : voir l'exemple complet

## Comparison

- objectif : aider a comparer deux options ou deux approches
- duree recommandee : 3 a 5 jours
- nombre moyen d'items : 3 a 5
- plateformes privilegiees : Facebook, Instagram, Snapchat
- CTA : comparer les options

## Testimonial

- objectif : renforcer la confiance via la preuve sociale
- duree recommandee : 3 a 4 jours
- nombre moyen d'items : 3 a 4
- plateformes privilegiees : Facebook, Instagram
- CTA : decouvrir le resultat ou prendre contact

## Seasonal

- objectif : profiter d'un temps fort de marche ou d'une saison
- duree recommandee : 5 a 14 jours
- nombre moyen d'items : 4 a 8
- plateformes privilegiees : Facebook, Instagram, Snapchat
- CTA : preparer la saison ou agir maintenant

## Product Update

- objectif : informer sur une evolution produit importante mais non majeure
- duree recommandee : 2 a 4 jours
- nombre moyen d'items : 2 a 4
- plateformes privilegiees : Facebook, Instagram
- CTA : voir la mise a jour

## Newsletter

- objectif : resumer une serie d'informations utiles dans une logique
  relationnelle
- duree recommandee : 1 a 3 jours
- nombre moyen d'items : 1 a 3
- plateformes privilegiees : Facebook, Instagram
- CTA : lire le recap ou s'abonner

## Promotion

- objectif : pousser une offre, un audit ou une action commerciale limitee
- duree recommandee : 3 a 7 jours
- nombre moyen d'items : 3 a 6
- plateformes privilegiees : Facebook, Instagram, Snapchat
- CTA : essayer, reserver ou demander un audit

## Regles generales

- un type de campagne doit rester lie a un objectif clair
- la duree doit rester proportionnee au niveau de nouveaute
- le nombre d'items ne doit pas saturer les plateformes
