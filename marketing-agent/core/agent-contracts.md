# Agent Contracts

## Objectif

Les contrats definissent ce que chaque agent recoit, ce qu'il produit, ce qu'il
assume et ce qu'il ne doit pas faire.

Ils servent a garder un systeme modulaire, previsible et non couple au code
applicatif.

## Knowledge Hub -> Orchestrator

### Input

- connaissance produit
- guides
- villes
- fonctionnalites
- regles de marque
- contexte editorial

### Output

- brief structure
- faits utiles
- angles possibles
- limites de formulation

### Responsabilites

- fournir une base fiable
- reduire les contradictions

### Ne doit pas faire

- choisir seul la strategie de publication
- publier

## Orchestrator -> Social Media Agent

### Input

- sujet retenu
- angle
- objectif du post
- reseaux cibles
- contraintes de ton

### Output

- variantes Facebook
- variantes Instagram
- variantes Snapchat

### Responsabilites

- transformer le brief en messages adaptes a chaque reseau

### Ne doit pas faire

- inventer des faits hors brief
- publier automatiquement

## Orchestrator -> Video Agent

### Input

- sujet
- objectif
- angle narratif
- assets disponibles

### Output

- concept video
- structure des scenes
- hook video
- idee de montage

### Responsabilites

- transformer un sujet en format video pedagogique

### Ne doit pas faire

- publier
- redefinir seul le message produit

## Orchestrator -> Content Agent

### Input

- sujet
- objectif editorial
- contexte Knowledge Hub

### Output

- brief de fond
- structure de message
- angles secondaires
- version longue ou base editoriale reutilisable

### Responsabilites

- clarifier le fond du contenu

### Ne doit pas faire

- prendre en charge toute la diffusion multicanal

## Orchestrator -> Translation Agent

### Input

- contenu source valide
- langue cible
- contraintes de ton

### Output

- variante traduite
- adaptation culturelle si necessaire

### Responsabilites

- rester fidele au message
- conserver la clarte et le ton

### Ne doit pas faire

- changer le fond marketing sans validation
- inventer une promesse plus forte que la source

## Orchestrator -> Image / Visual Agent

### Input

- sujet
- angle
- format cible
- contraintes de marque
- assets disponibles

### Output

- idee de visuel
- prompt image
- variantes
- recommandation de format

### Responsabilites

- rendre le message visuellement clair et coherent

### Ne doit pas faire

- publier
- redefinir seul la strategie editoriale

## Publisher Agent -> Analytics Agent

### Input

- contenu publie
- reseau
- date
- heure
- format
- campagne ou categorie

### Output

- suivi des performances
- comparaison des sujets
- recommandations de recyclage
- recommandations d'horaire

### Responsabilites

- transformer les resultats en apprentissages utiles

### Ne doit pas faire

- modifier retroactivement le contenu source
- tirer des conclusions fortes sans assez de donnees
