# Publisher Platforms

## Facebook

- formats : post, carousel, story, video
- medias acceptes : image, video, lien
- limites : lisibilite mobile, CTA simple, texte accompagne de media
- CTA : discover, learn more, book demo
- hashtags : utiles mais limites

## Instagram

- formats : feed, carousel, story, reel
- medias acceptes : image, video
- limites : fort poids visuel, texte secondaire, mobile-first
- CTA : link in bio, send message, discover feature
- hashtags : importants mais a garder pertinents

## LinkedIn

- formats : post, carousel, video, document
- medias acceptes : image, video, lien, PDF
- limites : ton professionnel, promesse claire, valeur concrete
- CTA : learn more, book demo, explore feature
- hashtags : peu nombreux et tres cibles

## X

- formats : short post, thread, video, image
- medias acceptes : image, video, lien
- limites : concision, rythme rapide, hook immediat
- CTA : read more, try it, explore
- hashtags : limites, plutot contextuels

## Threads

- formats : short post, thread, image, video
- medias acceptes : image, video, texte
- limites : ton conversationnel, rythme social, accroche legere
- CTA : join the conversation, discover, explore
- hashtags : usage leger

## TikTok

- formats : short video, cover, caption
- medias acceptes : video
- limites : vertical, hook tres rapide, rythme soutenu
- CTA : watch, discover, try it
- hashtags : importants mais selectifs

## YouTube

- formats : short, demo, thumbnail, description
- medias acceptes : video, image miniature, lien
- limites : clarte du titre, retention, structure narrative
- CTA : watch full demo, subscribe, learn more
- hashtags : secondaires

## Pinterest

- formats : pin image, pin video, tutorial card
- medias acceptes : image, video, lien
- limites : evergreen, visuel fort, texte lisible
- CTA : discover guide, save idea, learn more
- hashtags : faibles ou optionnels

## Blog

- formats : article, hero image, embedded video
- medias acceptes : texte, image, video, lien
- limites : structure SEO, lisibilite, profondeur
- CTA : read guide, request demo, explore feature
- hashtags : non pertinents

## Newsletter

- formats : email section, hero block, CTA block
- medias acceptes : image, video lien, texte
- limites : clarte, densite reduite, lien principal unique
- CTA : read more, discover feature, book demo
- hashtags : non pertinents

## Regles

- chaque plateforme doit rester explicite dans le Publication Job
- le format et le media doivent rester compatibles
- le CTA doit rester adapte au contexte de diffusion
- les hashtags doivent rester limites, utiles et tracables
