# Memory Model

## Objectif

La memoire de Norixo AI sert a garder une trace exploitable des sujets,
publications, decisions et performances pour eviter les doublons et rendre la
strategie plus coherente dans le temps.

## Publication Memory

### Role

Conserver l'historique des publications deja planifiees, validees, publiees,
refusees ou recyclees.

### Donnees conservees

- sujet
- angle
- plateforme
- format
- langue
- statut
- date
- campagne associee

### Usage par le Marketing Brain

- eviter la repetition
- mesurer l'equilibre editorial

### Usage par l'Orchestrator

- choisir la bonne declinaison
- savoir si une version existe deja

### Duree de conservation logique

- longue duree

## Topic Memory

### Role

Suivre les sujets deja traites, proposes, rejetes ou reportes.

### Donnees conservees

- titre de sujet
- categorie
- angle
- priorite
- statut
- date de derniere utilisation

### Usage par le Marketing Brain

- identifier les trous editoriaux
- prioriser de nouveaux angles

### Usage par l'Orchestrator

- verifier si un sujet a deja ete transforme en contenu

### Duree de conservation logique

- longue duree

## Campaign Memory

### Role

Conserver la memoire des campagnes et de leurs contenus relies.

### Donnees conservees

- nom de campagne
- objectif
- sujets relies
- plateformes
- periode
- statut

### Usage par le Marketing Brain

- arbitrer les priorites entre evergreen et campagnes

### Usage par l'Orchestrator

- relier un contenu a une campagne existante

### Duree de conservation logique

- longue duree

## City Memory

### Role

Savoir quand une ville a deja ete mise en avant et sous quel angle.

### Donnees conservees

- ville
- angle utilise
- date
- format
- plateforme

### Usage par le Marketing Brain

- eviter de promouvoir la meme ville trop souvent
- varier les marches abordes

### Usage par l'Orchestrator

- eviter les collisions de planning

### Duree de conservation logique

- moyenne a longue duree

## Guide Memory

### Role

Savoir quels guides ont deja ete repartages et comment.

### Donnees conservees

- guide
- angle de partage
- date
- plateforme
- format

### Usage par le Marketing Brain

- programmer les recyclages intelligents

### Usage par l'Orchestrator

- selectionner la meilleure forme de republication

### Duree de conservation logique

- moyenne a longue duree

## Feature Memory

### Role

Tracer les fonctionnalites deja communiquees et leur niveau de couverture.

### Donnees conservees

- fonctionnalite
- date de communication
- type de contenu
- campagne
- statut

### Usage par le Marketing Brain

- prioriser les nouveautes sous-exploitees

### Usage par l'Orchestrator

- verifier si une fonctionnalite a deja une base de contenu

### Duree de conservation logique

- longue duree

## Decision Memory

### Role

Conserver la trace des choix du Marketing Brain.

### Donnees conservees

- sujet choisi
- raison
- priorite
- alternatives ecartees
- date
- statut

### Usage par le Marketing Brain

- maintenir la coherence des arbitrages

### Usage par l'Orchestrator

- comprendre l'intention initiale avant execution

### Duree de conservation logique

- longue duree

## Performance Memory

### Role

Conserver les signaux de performance pour nourrir les cycles suivants.

### Donnees conservees

- vues
- clics
- likes
- partages
- commentaires
- conversions
- meilleur format
- meilleur horaire

### Usage par le Marketing Brain

- choisir les sujets et formats les plus prometteurs

### Usage par l'Orchestrator

- privilegier les variantes les plus coherentes avec l'historique

### Duree de conservation logique

- longue duree avec syntheses periodiques
