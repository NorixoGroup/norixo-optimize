# Decision Log

## Objectif

Le journal de decisions sert a comprendre pourquoi un contenu a ete produit.

Il permet de relier un choix editorial a son contexte, a ses sources et a son
objectif.

## Attributs d'une decision

- id
- date
- sujet choisi
- raison
- sources utilisees
- alternatives rejetees
- reseau recommande
- format recommande
- priorite
- statut

## Usage

- retracer les choix du Marketing Brain
- expliquer une priorite editoriale
- comprendre pourquoi un sujet a ete prefere a un autre
- preparer l'analyse future des performances
- documenter les arbitrages de campagne

## Regles

- chaque decision importante doit etre tracable
- les alternatives ecartees doivent rester visibles quand c'est utile
- le statut doit indiquer si la decision a ete executee, reportee ou abandonnee
- le log doit aider a comprendre les choix, pas seulement a lister des sujets
