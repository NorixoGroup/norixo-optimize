# Editorial Planning Workflow

## Workflow cible

Knowledge Hub
↓
Marketing Brain
↓
Topic Planner
↓
Editorial Calendar
↓
Orchestrator
↓
Content Agent
↓
Translation Agent
↓
Video Agent
↓
Publisher
↓
Analytics

## Lecture du workflow

### 1. Knowledge Hub

Le Knowledge Hub fournit la source de verite documentaire.

### 2. Marketing Brain

Le Marketing Brain decide les priorites editoriales et la logique de diffusion.

### 3. Topic Planner

Le Topic Planner convertit ces priorites en liste de sujets classes.

### 4. Editorial Calendar

Le calendrier editorial distribue les sujets dans le temps avec une cadence
equilibree.

### 5. Orchestrator

L'Orchestrator declenche ensuite les bons agents d'execution.

### 6. Content Agent

Le Content Agent produit la version source.

### 7. Translation Agent

Le Translation Agent adapte le contenu pour les langues cibles.

### 8. Video Agent

Le Video Agent prepare les formats video quand ils sont pertinents.

### 9. Publisher

Le Publisher prepare la diffusion selon le calendrier retenu.

### 10. Analytics

L'Analytics referme la boucle en nourrissant les futures decisions.

## Principes clefs

- decision centralisee
- aucun doublon inutile
- contenu equilibre entre themes et formats
- historique utilise pour orienter les choix
- amelioration continue a partir des performances
