# Content Production Workflow

## Workflow cible

Nouvelle information
↓
Knowledge Hub
↓
Orchestrator
↓
Content Agent
↓
Master Content
↓
Translation Agent
↓
11 langues
↓
Social Agent
↓
Video Agent
↓
Publisher
↓
Analytics

## Lecture du workflow

### 1. Nouvelle information

Une nouveaute, un guide, un cas d'usage ou une information produit entre dans
le systeme.

### 2. Knowledge Hub

Le Knowledge Hub structure l'information et la rend fiable.

### 3. Orchestrator

L'Orchestrator decide si le sujet merite une production editoriale et sous
quelle forme.

### 4. Content Agent

Le Content Agent redige une seule fois le contenu de reference.

### 5. Master Content

Le Master Content devient la source unique de travail pour les autres agents.

### 6. Translation Agent

Le Translation Agent adapte le contenu dans les 11 langues Norixo sans changer
le fond marketing.

### 7. Social Agent

Le Social Agent decline le contenu pour les reseaux cibles.

### 8. Video Agent

Le Video Agent transforme la meme source en logique video quand c'est pertinent.

### 9. Publisher

Le Publisher prepare la diffusion a partir de la meme base editoriale.

### 10. Analytics

Les performances sont rattachees a la source, pas a des versions inventees en
parallele.

## Principes clefs

- une seule redaction
- plusieurs declinaisons
- aucune duplication
- une source commune pour les reseaux, la video et la traduction
- pas de divergence marketing entre langues
