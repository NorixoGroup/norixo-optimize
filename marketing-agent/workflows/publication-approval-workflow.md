# Publication Approval Workflow

## Workflow cible

Marketing Brain
↓
Content Agent
↓
Translation
↓
Visual / Video
↓
Approval Model
↓
Safety Rules
↓
Validation humaine (phase initiale)
↓
Publisher Agent
↓
Analytics

## Lecture du workflow

### 1. Marketing Brain

Le sujet et la priorite sont decides en amont.

### 2. Content Agent

Le contenu source est redige a partir du cadre defini.

### 3. Translation

Les adaptations linguistiques restent fideles au contenu source.

### 4. Visual / Video

Les formats visuels et video sont prepares sans changer le fond du message.

### 5. Approval Model

Le contenu prend un statut clair dans le cycle de validation.

### 6. Safety Rules

Le contenu est confronte aux regles de securite et de coherence.

### 7. Validation humaine

La validation humaine est obligatoire dans les premieres versions de Norixo AI.

### 8. Publisher Agent

Le Publisher Agent n'agit qu'une fois les validations terminees.

### 9. Analytics

Les performances du contenu valide et publie sont ensuite mesurees.

## Regle clef

La validation humaine est obligatoire dans les premieres versions de Norixo AI.
