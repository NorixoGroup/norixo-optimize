# Image Workflow

## Workflow cible

Campaign Item
↓
Localized Content
↓
Image Agent
↓
Image Prompt
↓
Image Provider
↓
Generated Image
↓
QA
↓
Publisher

## Lecture du workflow

### 1. Campaign Item

Le Campaign Item fixe l'objectif visuel et le contexte d'usage.

### 2. Localized Content

Le contenu localise fournit le message, la langue et l'eventuel overlay.

### 3. Image Agent

L'Image Agent choisit le type, le format et les variantes.

### 4. Image Prompt

Le prompt structure traduit le besoin visuel en brief exploitable.

### 5. Image Provider

Le provider futur recoit le brief et produit une ou plusieurs sorties.

### 6. Generated Image

L'image generee devient un asset rattache a son job source.

### 7. QA

La QA verifie la conformite graphique, linguistique et de plateforme.

### 8. Publisher

Le Publisher prepare ensuite la diffusion avec le bon asset.

## Principes clefs

- une image doit remonter a un item source
- la langue et la plateforme doivent rester explicites
- aucune image ne doit partir sans QA
