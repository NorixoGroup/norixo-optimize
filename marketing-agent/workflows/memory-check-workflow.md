# Memory Check Workflow

## Workflow cible

Marketing Brain
↓
Topic Planner
↓
Memory Check
↓
Duplicate Prevention
↓
Decision Log
↓
Orchestrator
↓
Content Agent

## Lecture du workflow

### 1. Marketing Brain

Le Marketing Brain identifie un sujet prioritaire.

### 2. Topic Planner

Le Topic Planner transforme cette priorite en sujet concret a traiter.

### 3. Memory Check

La memoire est interrogee pour verifier :

- si le sujet existe deja
- si l'angle a deja ete utilise
- si la ville, le guide ou la fonctionnalite ont ete recemment promus
- si une decision similaire a deja ete prise

### 4. Duplicate Prevention

Les regles anti-doublons s'appliquent avant toute execution.

### 5. Decision Log

La decision retenue est enregistree avec son contexte et ses alternatives.

### 6. Orchestrator

L'Orchestrator n'agit qu'une fois la verification memoire terminee.

### 7. Content Agent

Le contenu n'est produit qu'apres validation de la memoire et de la decision.

## Regle cle

Aucun contenu ne doit etre produit sans verification memoire.
