# Video Workflow

## Workflow cible

Campaign Item
->
Localized Content
->
Image Assets
->
Video Agent
->
Video Script
->
Storyboard
->
Voice / Subtitles
->
Video Provider / Editing Tool
->
QA
->
Publisher

## Lecture du workflow

### 1. Campaign Item

Le Campaign Item fixe l'objectif, le contexte et le message prioritaire.

### 2. Localized Content

Le contenu localise fournit la langue, le ton et les formulations visibles ou
narrees.

### 3. Image Assets

Les assets image servent de base visuelle ou de support de storyboard si
necessaire.

### 4. Video Agent

Le Video Agent choisit le type, le format, le rythme et la structure generale.

### 5. Video Script

Le script organise le hook, le probleme, la solution, la demonstration et le
CTA.

### 6. Storyboard

Le storyboard traduit le script en scenes exploitables pour la production.

### 7. Voice / Subtitles

La voix et les sous-titres preparant la lisibilite, la narration et la locale
cible.

### 8. Video Provider / Editing Tool

Le futur moteur video ou outil de montage execute ensuite la production.

### 9. QA

La QA verifie la conformite narrative, visuelle, linguistique et de plateforme.

### 10. Publisher

Le Publisher prepare ensuite la diffusion avec le bon format et les bons
assets.

## Principes clefs

- une video doit remonter a un item source
- la langue et les sous-titres doivent rester explicites
- les assets images doivent rester tracables
- aucune video ne doit partir sans QA
