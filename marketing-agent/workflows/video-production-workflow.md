## Lecture du workflow

### 1. Nouvelle fonctionnalite

Une information produit ou un sujet prioritaire entre dans le systeme.

### 2. Knowledge Hub

Le Knowledge Hub reste la source unique d'information.

### 3. Orchestrator

L'Orchestrator decide si le sujet doit produire une video et sous quelle forme.

### 4. Video Agent

Le Video Agent transforme le brief en logique de production video.

### 5. Choix du format

Le format est choisi selon le canal et l'objectif :

- Reel
- Story
- Short
- tutoriel
- demonstration
- teaser

### 6. Script

Le message central est ecrit une seule fois comme base de narration.

### 7. Storyboard

Le storyboard transforme le script en structure visuelle exploitable.

### 8. Assets

Les captures, logos, voix, musiques, prompts ou references visuelles sont
rassembles.

### 9. Video Provider

Le moteur video execute la production a partir du package fourni.

### 10. Video Master

Une seule video master doit servir de base.

### 11. Validation

La validation humaine reste obligatoire dans la premiere version.

### 12. Declinaisons

La meme video master sert a produire plusieurs sorties adaptees.

### 13. Publication

La publication intervient seulement apres validation.

## Principes clefs

- une seule video master
- plusieurs langues
- plusieurs formats
- pas plusieurs montages quand une base unique suffit
- pas de publication automatique sans validation dans la premiere version
