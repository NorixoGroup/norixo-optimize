# Performance Analysis Workflow

## Workflow cible

Publisher Agent
↓
Analytics Agent
↓
Performance Model
↓
Learning Loop
↓
Marketing Brain
↓
Editorial Calendar
↓
Future Content

## Lecture du workflow

### 1. Publisher Agent

Le Publisher Agent fournit les contenus diffuses et leur contexte de
publication.

### 2. Analytics Agent

L'Analytics Agent collecte et normalise les donnees par plateforme.

### 3. Performance Model

Les resultats sont classes entre visibilite, engagement, trafic, conversion et
apprentissage.

### 4. Learning Loop

Les resultats sont transformes en tendances et recommandations utiles.

### 5. Marketing Brain

Le Marketing Brain adapte ses futures priorites a partir de ces apprentissages.

### 6. Editorial Calendar

Le calendrier editorial integre les recommandations de sujet, format et timing.

### 7. Future Content

Les nouveaux contenus partent d'une strategie deja enrichie par la performance.

## Rythmes d'analyse

### Analyse quotidienne

- surveiller les premiers signaux
- reperer les anomalies
- detecter les bons horaires emergents

### Analyse hebdomadaire

- comparer les formats
- comparer les sujets
- identifier les contenus a recycler

### Analyse mensuelle

- observer les tendances stables
- ajuster les priorites editoriales
- identifier les themes vraiment performants

## Recommandations attendues

- meilleurs sujets
- meilleurs formats
- meilleurs horaires
- contenus a recycler
- contenus a retravailler
- contenus a abandonner
