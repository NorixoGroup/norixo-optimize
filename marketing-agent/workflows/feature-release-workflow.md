# Feature Release Workflow

## Objectif

Documenter le workflow cible lorsque Norixo ajoute une nouvelle fonctionnalite
ou une nouveaute produit importante.

## Sequence cible

Nouvelle fonctionnalite
↓
Knowledge Hub
↓
Orchestrator
↓
Content Agent
↓
Social Media Agent
↓
Video Agent
↓
Image Agent
↓
Translation Agent
↓
Publisher Agent
↓
Analytics Agent

## Lecture du workflow

### 1. Nouvelle fonctionnalite

Une nouveaute produit est documentee une seule fois de maniere claire.

### 2. Knowledge Hub

Le Knowledge Hub devient la source d'information centrale :

- description de la fonctionnalite
- cas d'usage
- valeur apportee
- limites
- vocabulaire recommande

### 3. Orchestrator

L'Orchestrator choisit :

- quels canaux activer
- quels agents declencher
- quel angle privilegier
- si la nouveaute doit etre decoupee en plusieurs contenus

### 4. Content Agent

Le Content Agent produit un message de fond reutilisable :

- benefice principal
- objections possibles
- explication pedagogique

### 5. Social Media Agent

Le Social Media Agent declenche les variantes reseaux :

- Facebook
- Instagram
- Snapchat

### 6. Video Agent

Le Video Agent prepare un angle video si pertinent.

### 7. Image Agent

L'Image Agent propose :

- idee de visuel
- prompt image
- variantes

### 8. Translation Agent

La declinaison multilingue future doit partir de la meme information source,
pas de reinterpretations paralleles.

### 9. Publisher Agent

Le Publisher Agent prepare les contenus mais ne publie pas automatiquement dans
la premiere version.

### 10. Analytics Agent

Il observe les performances et nourrit les cycles suivants.

## Principes clefs

- une seule information source
- declinaison multicanal a partir d'un brief commun
- declinaison multilingue future a partir du meme noyau
- aucune publication automatique sans validation humaine dans la premiere
  version
