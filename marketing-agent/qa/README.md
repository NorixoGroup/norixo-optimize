# Marketing QA Framework

## Objectif

Ce dossier contient le cadre qualite de Norixo AI pour les scenarios marketing.

Il permet de rendre chaque scenario :

- comparable
- mesurable
- reproductible
- ameliorable

## Perimetre

Le framework couvre :

- le template officiel des scenarios
- la checklist qualite
- la grille de score
- la logique de regression
- le modele de lessons learned

## Regle cle

Un scenario valide devient une reference de qualite pour les evolutions
suivantes du systeme.
