# Scenario Scorecard

## Objectif

Evaluer un scenario marketing sur une base comparable.

## Criteres

- Pertinence
- Originalite
- Clarte
- Valeur ajoutee
- Coherence produit
- Coherence branding
- CTA
- Reseaux
- Qualite video
- Qualite image
- Traductions
- Reutilisabilite

## Evaluation

Pour chaque critere :

- note attribuee
- commentaire court
- point d'amelioration si necessaire

## Score final

Score global /100

## Interpretation

- 90-100 : scenario de reference
- 75-89 : scenario solide avec ajustements mineurs
- 60-74 : scenario exploitable mais incomplet
- <60 : scenario a retravailler avant validation
