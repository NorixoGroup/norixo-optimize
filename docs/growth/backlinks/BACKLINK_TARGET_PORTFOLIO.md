# Purpose

Centralize all editorial targets approved for Norixo's backlink campaign. This document is the source of truth from which the future outreach CRM will be populated.

Each domain has a permanent identifier. Identifiers are never recycled; new domains receive the next available identifier. These immutable identifiers are the unique reference for the portfolio, the future CRM, and reporting.

# Qualification criteria

Each domain added to the portfolio must be assessed against the following criteria:

- Editorial quality
- Relevance to the short-term rental sector
- Credibility
- Qualified traffic
- Authority
- Professional audience
- Realistic opportunity for a natural citation

_Domain-specific qualification evidence will be added when the approved portfolio is populated._

# Portfolio structure

The portfolio will organize approved domains into the following categories:

- Media
- Blogs
- Revenue Management
- PMS
- Associations
- Universities
- Communities
- Podcasts

_No category is populated in this template._
